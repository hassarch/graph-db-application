================================================================================
RESEARCH KNOWLEDGE GRAPH EXPLORER - QUICK SETUP GUIDE
================================================================================

This is a complete graph database application built with:
- CognoDB (graph database)
- Node.js + Express (backend)
- React + Vite (frontend)

================================================================================
STEP 1: INSTALL DEPENDENCIES
================================================================================

npm install

================================================================================
STEP 2: SET UP COGNODB
================================================================================

1. Go to: https://console.cognodb.com/signup
2. Create a free account (no credit card needed)
3. Create a free (c0) instance
4. Copy your connection details:
   - URI: bolt+s://xxxxx.databases.cognodb.cloud
   - Username: cognodb
   - Password: [shown only once - copy immediately!]

================================================================================
STEP 3: CONFIGURE ENVIRONMENT
================================================================================

cp .env.example .env

Edit .env with your CognoDB credentials:

COGNODB_URI=bolt+s://your-instance.databases.cognodb.cloud
COGNODB_USER=cognodb
COGNODB_PASSWORD=your-generated-password
PORT=3000
NODE_ENV=development

================================================================================
STEP 4: VERIFY SETUP
================================================================================

npm run verify

This checks:
- Node.js version
- Environment variables
- Dependencies
- Project structure
- Database connection

================================================================================
STEP 5: LOAD SAMPLE DATA
================================================================================

npm run seed

This creates:
- 15 authors
- 15 papers
- 10 topics
- 10 institutions
- 6 countries
- Citations, collaborations, and affiliations

================================================================================
STEP 6: START THE APPLICATION
================================================================================

npm run dev

This starts:
- Backend server on http://localhost:3000
- Frontend dev server on http://localhost:5173

Open http://localhost:5173 in your browser

================================================================================
STEP 7: EXPLORE THE APPLICATION
================================================================================

Try these:

1. SEARCH
   - Search for "Chen" (finds Dr. Sarah Chen)
   - Search for "Attention" (finds famous paper)
   - Search for "Machine Learning" (finds topic)

2. COLLABORATION PATH
   - From: "Dr. Sarah Chen"
   - To: "Prof. David Kim"
   - See the connection through papers

3. ANALYTICS
   - View database statistics
   - See influential authors
   - Explore cross-institutional collaborations

================================================================================
TROUBLESHOOTING
================================================================================

DATABASE CONNECTION ERROR:
- Verify .env file exists and has correct values
- Check CognoDB instance is running at console.cognodb.com
- Ensure URI starts with bolt+s://
- Verify password is correct

PORT ALREADY IN USE:
- Change PORT in .env to 3001
- Or kill process: lsof -ti:3000 | xargs kill -9

BUILD FAILS:
- Delete node_modules and package-lock.json
- Run: npm install
- Try again: npm run build

SEED FAILS:
- Verify database connection works first
- Clear database in CognoDB console: MATCH (n) DETACH DELETE n
- Run seed again: npm run seed
